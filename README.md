# 漫剧工坊 · Manju Studio

以本地运行为主的 AI 漫剧制作工作台。把故事原稿、大纲、角色、场景、剧本、分镜、图片和视频集中在一个项目中管理，支持分阶段生产、补产和成片拼接。

语言模型接口由使用者自行配置，图片与视频由自己的 ComfyUI 工作流生成。项目和生成素材保存在本地。

## 功能

- **项目管理**：每部作品独立保存原稿、分集、设定、分镜和素材。
- **前期创作**：整理情节，生成大纲、角色、场景、剧本、站位和分镜，执行结构检查。
- **素材生产**：生成场景图、角色参考图、关键帧及分段视频。
- **工作流配置**：导入 API 格式工作流，设置提示词、参考图和输出节点映射。
- **批量与补产**：默认跳过已有素材，可按集或视频段补产、重新生成。
- **长任务**：图片、视频等批量阶段不设置整批累计时间上限；单个请求仍保留超时和错误处理，可手动停止。
- **成片拼接**：通过本机 FFmpeg 拼接视频段。

## Windows 桌面版

在 [Releases](https://github.com/qiukaihui/manju-studio/releases) 下载 `ManjuStudio-版本号-Windows-x64.zip`，解压整个文件夹，双击 **漫剧工坊.exe**。

不要只复制其中的 exe 文件。桌面版不需要单独安装 Node.js，不附带模型权重或个人密钥。

桌面版目前属于预览版本，尚未完成 Windows 真机与不同模型环境的完整验收。

## 从源码启动

需要 Node.js 22 或更高版本。基础服务没有额外的 npm 运行依赖。

```bash
git clone https://github.com/qiukaihui/manju-studio.git
cd manju-studio
npm start
```

打开 `http://127.0.0.1:7799`。该方式在本机启动服务和界面，不需要桌面安装包。

### 首次配置

1. 在“设置”中填写自己的语言模型接口地址、模型名称、协议和 API 密钥，并测试连接。
2. 启动本机 ComfyUI，填写地址，通常为 `http://127.0.0.1:8188`。
3. 使用内置工作流，或导入自己的 API 格式工作流。选择输入、输出节点后保存。
4. 新建项目，导入或粘贴原稿，设置集数、单集时长、题材和画风。
5. 先用一小段内容验证工作流，再按需要选择前期创作、出图、视频生成和拼接阶段。

图像、视频生成需要使用者自行安装 ComfyUI、模型和相关节点。视频拼接另外需要 FFmpeg：将其加入 PATH，或通过 `DSH_FFMPEG` 指定可执行文件。

## 默认工作流

| 用途 | 默认工作流 |
| --- | --- |
| 场景、角色出图 | Qwen Image 2.1 文生图 |
| 分镜关键帧 | Qwen Image 2.1 图生图 |
| 分段视频 | MiniMax H3 参考图视频 |

三套工作流的节点映射已预设。内置 H3 视频按分镜切点顺序传入关键帧，最多使用四张参考图。

不限定显卡型号和显存容量，实际硬件需求由所选模型与工作流决定。工作流可以替换，模型文件名和节点需要与自己的 ComfyUI 环境对应。

首次运行自动载入默认配置。已有自定义配置不会被自动覆盖；升级后如需恢复默认，可在设置中点击“恢复内置工作流”，再保存。

## 数据与联网范围

| 运行方式 | 项目位置 | 设置与日志 |
| --- | --- | --- |
| 源码启动 | 仓库下 `projects/` | 仓库下 `data/` |
| Windows 桌面版 | 文档／漫剧工坊项目 | 当前用户的应用数据目录 |

使用联网语言模型接口时，相关故事、剧本和任务文本会发送至使用者配置的接口。图像、视频由所配置的 ComfyUI 工作流执行；需要本地生成时，请使用本地模型节点。

仓库和源码包不包含个人密钥、私人项目或生成素材。程序包含文件读写和命令执行功能，仅面向可信的本机使用，不是可直接部署到公网的多用户服务。

## 开发与构建

运行回归测试：

```bash
npm test
```

准备桌面运行目录并在开发环境打开：

```bash
npm --prefix studio/desktop ci
npm run desktop:prepare
npm run desktop:start
```

构建 Windows x64 压缩包：

```bash
npm run build:win
```

结果在 `studio/desktop/release/`。源码与桌面运行资源均不做代码混淆或文档加密。

## 当前边界与反馈

生成结果需要人工检查，尤其是人物一致性、动作连续性、台词、声音和字幕。连接 ComfyUI 成功，不代表每套工作流的模型与节点已经齐全。超分请在自己的工作流中配置。

提交 Issue 时，请提供软件版本、系统、操作步骤、工作流类型，以及经过脱敏的报错日志；不要上传密钥或令牌。
